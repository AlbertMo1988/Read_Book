# 以后，沟通的亏，就别吃了

- 来源：印象笔记 → `00 新收集` → 同名收藏；笔记 ID：`6413d91f-debd-43e6-88f5-0099b55691b7`。
- 收藏署名：刘润主创团，谢春霖提供观点，阿畴主笔，李桑责编。本文记录主要观点和可复用方法，不另存原文。

## 核心观点：先判断卡在哪一关

**对方没行动，不一定是你没讲清，也不一定是他不同意。先区分「不想听、听不懂、不认同、不行动」，再解决眼下的障碍。** 说服不是替对方下结论；你能做的是让对方有机会听懂、独立判断，选择是否采取行动。

| 卡点 | 原文的主要方法 | 行动方法 |
| --- | --- | --- |
| **不想听**：信任、时机、情绪、开口资格或内容不合适 | 长期信任靠善意、能力和一贯性；初次接触可借可信的人、机构或已有成果背书。对方没空就约时间或换场合；情绪紧张先理解关切；给建议前先征得同意，从对方重视的问题切入。 | 先确认一句：「我想聊的是交期这个风险。你现在方便听两个发现，还是我另约十分钟？」如果对方正在着急，先确认他在担心什么，不急着递方案。开口许可不是正式决策授权。 |
| **听不懂**：缺少背景，或术语、表达结构让人跟不上 | 会前补必要背景；用对方熟悉的词和具体事例；信息按结构讲。 | 会前只给一页，让对方知道要读什么、会上要决定什么。开口按「结论 → 关键事实 → 要做的决定」讲。用一个开放式问题确认理解，比如：「按这个描述，你觉得现在要先确认哪个风险？」 |
| **不认同**：可能是事实、标准、优先级或利益不同 | 从为原有观点找证据的「律师模式」，切换到愿意用证据修正结论的「科学家模式」。原文建议以提问、故事或亲身体验帮助对方产生自己的判断。 | 别把不同意都归因于偏误，先问：「我们不同意的是事实、验收标准，还是资源优先级？」再问：「什么证据会改变你的判断？什么证据会改变我的？」故事用来帮助理解，不替代证据；体验可用自愿的小试验。 |
| **不行动**：认同不等于有权限、有把握或知道第一步 | 说明延后的真实代价，消除顾虑，降低启动门槛。原文举了截止时间、可反悔和拆小动作等例子。 | 先问：「现在不动，是还有顾虑，还是缺人、时间或授权？」只定一个最小动作和真实期限，确认谁来做、需要什么支持、何时看结果。如果没有人有权限答应，就记为「待决定」，不记成承诺。 |

## 我的理解：不要把方法用成施压

- **接住情绪不等于认同结论。** 可以说「我听到你担心额外的工作最后都落到你们身上」，但不必在未核实时同意「别人故意推责」。文章里的脑区说法和 NLP 假设不是实践这些方法的前提。
- **让对方自己判断，不是循着预设结论诱导。** 文章提到利用认知失调和制造竞争感。更适合长期合作的做法是把选项、成本和不确定性讲明，让对方能试、能退出，也能拒绝。不虚构截止日期、背书或竞争者。
- **不是所有的对话都要说服。** 告知、听取顾虑、厘清分歧，本身也可能是成果。涉及共同交付时，才需要明确决定和后续动作；也不要把资源、权责或技术问题误诊成「还没沟通到位」。

## 下次就能用：会前五分钟、会后三行

**会前**写下三件事：对方最在意什么（不知道就问）；我需要他理解、判断还是行动；我能提出的最小请求是什么。

**会中**如果对话停住，先定位，不叠加论据。可以问：「我先确认一下：是我没把背景讲清，还是你理解了，但对方案或现在投入资源有顾虑？」接到顾虑后复述，再决定补材料、做对照，还是找有权决定的人。

**会后**只记三行：① 已达成的共识；② 没有解决的分歧或待决定事项；③ 谁在什么时候做什么、到时拿什么来核对。没有明确认领，就不把「收到」写成「同意推进」。

**用于跨 BU 讨论的例子（整理者延伸）：** 如果双方已经认同一个技术问题值得解决，但还没动作，没必要再花十分钟强调其重要性。先问是没有可用样本、没有人做验证，还是没有权决定验证路线；然后只争取一个小承诺，例如由有权限的一方在约定时间内确认能否提供同口径样本。会后核对样本、明确不可提供的原因，或需要升级的决定，而不是只核对谁回复了消息。可参照你此前记录的[「局部尽责、整体失责」](../courses/044-文明之旅-北宋汴京保卫战-系统性的不负责.md)。
