# 做到这六点的领导者，从来都是少数

- 来源：印象笔记 → `00 新收集` → 同名收藏；笔记 ID：`dcb5e548-e658-498a-8826-33da49f7de76`。
- 收藏署名：《哈佛商业评论》中文版；罗恩·阿什肯纳斯（Ron Ashkenas）、布鲁克·曼维尔（Brook Manville）撰文，阿丫丫译，周强编校。本文记录观点和行动方法，不另存原文。

## 主要观点

文章回答的是：**怎样把擅长本职工作的骨干，培养成能组织一群人实现共同结果的领导者？** 作者根据《HBR Leader’s Handbook》的访谈与回顾，归纳出六种基本做法。组织变得更扁平、协作更跨界，工具也在变，但领导力的任务仍是让人围绕一个值得做的目标共同取得结果。六点不是固定步骤，哪一点优先取决于当前最缺什么。

| 做法 | 主要观点 | 可尝试的行动 |
| --- | --- | --- |
| **1. 凝聚愿景** | 愿景要让团队看到达成以后有什么不同，并愿意为此投入。领导者可以先提出方向，再让团队把它说得更具体。 | 用一句话写清：「到某个时间，哪类客户或一线同事会看到怎样的变化？」让大家各举一个达成愿景时会看见的事实，检验是否理解的是同一件事。 |
| **2. 制定策略** | 策略是决定做什么、不做什么，以及怎样配置有限资源；不能只把愿景拆成更多任务。 | 选一个优先突破口，写清一项暂缓的工作和为此腾出的人、时间或预算。若团队说不出什么会被放下，就还没有真正做取舍。 |
| **3. 吸引和发展人才** | 用能实施策略的人，并通过真实任务、反馈和支持帮他们成长。安排和调整角色首先要服务于策略，而不是只看资历或一味要求原班人马多做。 | 选一个边界清楚的结果交给一位骨干，先讲清可自行决定的事、需要的支持和升级条件。复盘时看他是否能独立推动结果，再判断是要辅导、增加资源，还是调整角色。 |
| **4. 持续关注结果** | 计划和行动是手段，最终要看策略有没有带来预期结果。保持持续关注，结果偏离时及时调整。 | 定一个能验收的结果和一两个过程信号。周会上不数开了几次会，只核对：结果有什么变化、证据是什么、偏差需要谁作决定。 |
| **5. 持续创新** | 创新不只是加一个点子或工具，而是根据结果重新评估做法；有时新证据会改写策略甚至愿景。 | 选一个反复出现的卡点，试一种不同的交接或验证方式。先定好对照口径：什么变化值得保留，什么结果说明应撤回或换方向。 |
| **6. 自我领导** | 领导者也要更新自己：认识自己的短板，学习分配时间、争取支持、改进判断，而不只要求团队改变。 | 每周从一个实际决定复盘：「我哪里给了清楚的方向？哪里替别人做了决定？哪项支持只有我能争取？下周我只改哪一个动作？」找一位合作同事核对你的自评。 |

## 文章案例：六点怎样连起来

XL 保险案例里，塞雷娜·玛西亚先把一个稳定但增长慢的部门带向更有抱负的目标，再与经理们讨论在哪些产品和市场投入。她调整团队、推动具体行动，并让团队根据实际反馈改变承销商与代理人的合作方式。她自己也改变了时间分配、争取其他部门支持和作人事决定的方式。案例的重点不是照搬增长目标或施压方式，而是看到：**目标、手段、团队配置、结果反馈和领导者自身行为，要一起变。**

## 结合团队工作：这周先试一件事

结合此前记录的[「局部尽责、整体失责」](../courses/044-文明之旅-北宋汴京保卫战-系统性的不负责.md)，如果大家都很忙，但一个跨团队问题反复出现在周会上，优先检查第 2、3、4 点：**有没有做取舍，有没有人能为结果行动，有没有共同认可的结果证据？** 这不预设问题一定是责任不清：也可能是真有技术难题、能力缺口，或关键资源尚未到位。

1. **用一个真实项目选突破口。** 先问「这周如果只能推动一项，哪项最可能改变客户交付或产品决策？」并明确哪项先放下。
2. **把一个可验收的小结果交给一个人。** 例如「用同一口径验证两份结果是否可比，并据此建议下一步」，而不是泛泛要求「跟进技术问题」。约好可自主协调的范围；跨部门资源或正式决策仍由有权限的人确认。
3. **下次会上先看证据，再看领导行为。** 证据可能是完成的验证、已排除的假设，或一个写清由谁决定的未决事项。然后复盘：是团队缺方法，还是我没有做取舍、给权限、争取支持？如果没有学到新东西，不只是催得更紧，而是换一个验证办法。

**下次开会可以问：**「如果下周这个问题还在名单上，我们至少要拿出什么证据，说明它确实向前走了一步？谁来做这个动作，又有什么必须由我或其他负责人先决定？」
