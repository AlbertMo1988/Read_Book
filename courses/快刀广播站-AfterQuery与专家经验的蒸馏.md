# 快刀广播站｜AfterQuery 与专家经验的蒸馏

- 来源：快刀青衣《快刀广播站》，依据用户贴出的文字稿整理。此标题为整理标题，未核实节目原题与期号。
- 范围：记录文章主线、五步操作方法和读者感悟。融资估值是节目转述的未完成交易口径；人员规模、客户与训练用途也仅按节目转述，不作为独立核验的结论。

## 一句话理解

**能复用的不是专家那句「这儿不太对」，而是他在什么条件下、看到什么证据、做出什么判断，以及哪些例外会让他改变判断。** 把这一小段做成一道可评审、可验证的任务，比模仿专家的口气更接近传承经验。

## 文章主线

1. **专业 AI 缺的不只是知识，更是情境里的判断。** 教科书解释并购是什么，却未必记录一位资深从业者拿到材料后先看什么、什么时候停下来核实。专家往往已经把这类动作做成了习惯，直接问「讲讲你的方法论」，可能只得到一句「凭感觉」。
2. **AfterQuery 从 Agent 失败中找到另一个问题。** 按节目叙述，团队原先尝试做金融与专业服务 Agent，演示之外碰到幻觉、细节判断和行规等障碍。团队转而问：模型到底在哪一个动作上失败？能否把缺少的判断做成专家可生产、可复核的训练材料？
3. **它卖的不是专家答题时间，而是把判断转成可评分信号的能力。** 关键不是多收集成功答案，而是定义哪些回答看起来合理却不该过、哪些证据缺失时应该暂缓判断。节目引述报道说相关数据进入了英伟达一款模型的训练流程；文本未给出使用阶段、权重或独立贡献，不能据此断言某个能力提高了多少。
4. **风格像，不等于判断像。** 用既有内容做数字分身，能保存某个时点的内容、语气和表达。真正的专家会在新的实际工作里碰到反例、修正规则。节目以课程选题和学员跟不上讲解节奏作例子，强调人要持续在一线做事，才能更新判断。
5. **分享旧经验与继续长出新经验，不是同一件事。** 节目用编兜篮的老人尝试新花样作类比：技能积累并未失效，持续适应变化让它有了新的用途。这里是对成长的启发，不能据此推断分享经验就不会带来岗位调整。

## 原文方法：从失败案例到训练数据

| 步骤 | 要完成什么 |
| --- | --- |
| 1. 找失败 | 从真实工作流里定位模型栽在哪一个具体动作，而不是笼统地说它「不懂这个行业」。 |
| 2. 缩成一道题 | 说明输入、要做的判断和输出边界，让对错有办法区分；需要的证据不够时，允许作出「暂不能判」的回答。 |
| 3. 写评分细则、配自动校验 | 专家把通过、不通过和例外写成条；程序检查能形式化的部分。诸如结论是否合理这类尚不能稳定形式化的判断，仍需人复核。 |
| 4. 让专家做题并互审 | 不只给答案，也指出关键证据和常见误判。对于专家之间尚有争议的案例，不强行统一成所谓标准答案。 |
| 5. 小规模训练并验收 | 按节目讲法，以分数检验模型是否改进了这个动作。用于团队试点时，最好留一组没用于示范或训练的新案例，避免把做对原题误当成学会判断。 |

在本文中，「经验蒸馏」是**提取并验证判断方法**的比喻。产品团队可以先用一页评分细则和案例试用，不必一开始就训练模型。

## 讲得最清楚的例子：审课程

节目举例：资深编辑听到第三讲，判断「内容没有错，但学员到这里会跟不上」。下列是我们讨论时用来说明机制的示例，并非节目报告过的实验。

假设第三讲有句「现在请根据转化漏斗，判断应该优先改善哪个环节」，但前两讲没有解释「转化漏斗」。编辑觉得要改，是因为**讲稿要求学员马上用一个尚未建立的概念完成判断**，不是因为这一讲术语多、讲得快，或内容事实有误。

- **怎么取出经验：** 给编辑看两版讲稿，不先请他概括原则，而是问「你从哪一句开始觉得学员会掉队？如果前两讲已经教过这个概念，你还会标这句吗？」通过这一对照找出真正改变判断的条件。
- **怎么出题和判分：** 提供前两讲讲稿和第三讲片段，只要求标出第一次出现的前置知识断点、引用对应句子、指出缺了什么。单纯列生词不算对；如果概念已经解释，不能误报；材料不齐时要指出缺哪一讲。程序可以检查引用句子是否真的在材料中，是否足以让初学者跟上，仍由编辑判断。
- **怎么知道有效：** 拿几组新的讲稿片段，由编辑先独立标注，再比较 AI 有、没有这套规则时的漏报和误报；不要拿刚刚给它看的示例验收。
- **刻意保留的边界：** AI 先找断点，编辑再决定补概念、加例子，还是重排讲法。前者是一项能单独训练和检验的判断，不等于复制整位编辑的品味。

## 我的感悟（读者）

我想弄明白的不只是「经验可以蒸馏」，而是**怎样才算有效地蒸馏**。审课程的例子让我看清：要从一个具体判断和对照案例里找线索，不能只问专家有没有总结。

另一个问题是：**专家怕自己的工作被拿走，靠什么让他愿意贡献经验？** 一次性整理能沉淀的是过去的经验，在生成完的那一刻就固定下来；一个人的持续价值，是他还能在真实工作里产生新的经验。

## 讨论延伸（整理者）

专家的顾虑并非只是怕学习。交出过去的判断之后，可能失去决定权、晋升机会，或沦为 AI 的兜底审核者。**让专家继续创造新经验，首先是组织给不给他时间、位置、权力和认可的问题。**

- 从专家自己想少做、团队却常做错的一项重复判断开始，说明案例用途、可访问范围和退出条件，不以交出全部经验为前提。
- 让专家共同决定通过标准、保留例外和复核权；把标准维护、发现新例外和带教算作可见贡献，而不是额外的隐形工作。
- 事先说清节省下来的时间去哪里，例如处理更难的案例、试新做法或培养新人。如果确有岗位调整计划，应诚实说明，不作无法兑现的保证。
- 第一轮衡量两个结果：新人或 AI 是否更少反复来问同一件事，专家是否真能腾出时间去接触新问题。只有第一项改善，不代表组织解决了第二项。
