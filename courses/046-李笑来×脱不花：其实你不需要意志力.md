# 李笑来×脱不花：其实你不需要意志力

来源：[得到《长谈》第5期](https://www.dedao.cn/course/article?id=BQe6EGjvO7zRKZq0mmXnDrkMLPgAp9)。已用此前验证的匿名只读方式获取并分段核读正文，提取文本约 4.2 万字符。本文是原创提炼；节目另有图片版思维导图与行动指南，本笔记的行动计划由 AI 根据文字稿设计，并非该附件的转录。

## 读者的五点提炼

1. **自我对话可以用于两种改变。** 想“退出”一个坏习惯，或“组建”一个好习惯，都可以尝试这个方法。
2. **用自己的声音反复说，再以实际好处巩固。** 自我陈述＋一个理由＋情绪感受，是说给自己听的部分；改变之后罗列真实好处，是巩固的部分。读者以“欺骗”潜意识概括节目对这个过程的描述；这是访谈使用的比喻，不是已验证的机制结论。
3. **脚本具体到身份或行为。** 下表保留读者整理的表达。各例不必硬凑成同一个长度或结构。
4. **习得性无助可能阻碍再次尝试。** 反复失败后，人可能在新一轮开始前就觉得“反正我也做不到”。可以先做一次范围小、结果看得见的尝试，给自己积累新的证据，而不是继续用以往失败定义自己。
5. **朗读值得单独记下来。** 自我对话强调把话说出声、听到自己的声音；访谈后半段也单独讨论读材料时的朗读，尤其提及外语。两者都用了声音，但用途不同，不能由此推断默读无效或朗读能预防疾病。

| 场景 | 读者摘记中的自我对话示例 |
|---|---|
| 戒烟 | 我是一个从来不抽烟的人，因为烟很臭，抽烟我就不开心。 |
| 健身 | 我是一个每天都去健身房的人。 |
| 挤吧眼 | 我从来不乱眨眼睛。 |
| 写作 | 我每天要写3000字的思考。 |
| 减肥 | 我从来不多吃，因为吃多了不舒服。 |

写作例子的重点是为写作留出思考时间，而不是只追求字数。表中的戒烟、眨眼、健身与饮食表达记录的是节目和读者的例子，不作为治疗方法、每日训练量或个人饮食目标。

## 一句话理解

把反复发生的行为放回具体情境里：找到触发它的线索，用一句简短的自我提示和一个容易开始的动作，替代每天临场硬扛；再用实际结果检验它是否值得继续。

## 核心观点

### 1. 改习惯，先看它和哪些场景连在一起

李笑来用吸烟举例：泡咖啡、等电脑启动、出门、社交，都可能与吸烟形成联系。一个看似单一的习惯，实际可能在多个场景里反复触发。改变之前，可以先找最常发生的一种情境，观察它之前和之后各发生了什么。

访谈对“线索—行为—奖励”三要素模型提出质疑。这是嘉宾的解释，不宜据此认定奖励对习惯没有作用。

### 2. 自我对话：身份、动作、理由与感受

访谈建议用自己的声音反复表达一种自我定义，再给出理由和情绪感受。最值得保留的是：**身份要由可执行动作体现。** “我要更专注”难以判断是否做到了；“打开资料后先读两分钟”可以立即执行。

把提示语说出来、录成语音、试用第二语言或用名字称呼自己，是节目提供的变体。可按舒适度尝试，不必全做。这里把自我对话当成启动行动的提示，不要求强迫自己相信与事实不符的陈述。

### 3. 组建习惯：先稳定开始，再考虑提高强度

脱不花的健身案例把第一步定义为“到健身房”，而非每次都达到某个训练量。新行为需要时间，也会挤占旧活动；把行为接到已有日程上，往往比设定更大的结果指标更便于重复。

访谈还用写作说明：字数可以检验是否动笔，却不一定检验思考质量。若目标是理解问题，指标应包括澄清了什么判断，而不是只数文字。

### 4. 手机分心适合调整环境，而不仅是改变说法

节目提出把手机放到视线之外、减少通知、试用灰度显示，并练习在一段时间内只读书或看一部作品。它们的作用是减少拿起手机的机会，而不是要求每次都抵抗同一个提示。实施时可保留真正需要及时回应的联络方式。

### 5. 用真实反馈巩固改变，保留修订的自由

嘉宾记录改变后实际得到的好处，作为继续的理由。是否退出某种习惯，由它对自己的影响决定，不必把所有偏好划分为好坏。脱不花也强调，值得追求的是有选择的余地，而非每一项都做到完美。

### 6. 用同样的办法学习：明确问题、读材料、再验证

访谈后半段把阅读和研究视为基础能力：进入陌生领域时先容许暂时看不清，逐步分类材料、形成问题地图。AI 可以帮忙完善问题、找资料线索和梳理术语；论文是否存在、链接是否有效、结论是否由原文支持，仍要亲自核验。

## 可用与待验证的部分

- **可以低成本试行：** 找具体场景、缩小第一步、改变提示环境、记录反馈。习惯形成速度因人和行为而异，不把一周或固定天数当成自动化的保证。[Lally 等人的习惯形成研究](https://onlinelibrary.wiley.com/doi/10.1002/ejsp.674)
- **作为嘉宾个人经验记录：** 自我对话帮助其改变吸烟行为；脱不花借此坚持健身、写作。个案不能证明同一方法对所有人都有效。若实际目标是戒烟，可把自我提示作为辅助，寻求循证的行为支持和专业指导。[WHO 成人戒烟指南](https://www.who.int/publications/i/item/9789240096431)
- **不作为行动依据：** 访谈对潜意识的固定领先秒数、用特定时长说话阻断冲动、外语必然更有效，以及手机使用或朗读对脑病的推断，未在本笔记中得到独立验证。不据此作医学、儿童发展或训练决策。

## 行动计划：七天只试一个动作（AI 整理）

### 可选试验：为一个自己想改变的习惯写脚本

这是一项独立的习惯练习。先选一个自己确实想退出或组建的日常行为，再确定它出现的场景。下面以“晚饭后朗读两分钟”为可替换示例，并未替读者选定目标。

| 时间 | 行动 | 判断标准 |
|---|---|---|
| 开始前 | 选一个场景、一项行为，写一句带有动作、理由与真实感受的脚本；把要读的材料提前放好 | 知道什么时候开始、开始时做什么 |
| 第1—3天 | 场景出现时，用自己的声音说一遍，再做最小动作，例如朗读两分钟 | 记录是否开始、开始有多费力 |
| 第4—6天 | 保留同一场景，记下实际得到的好处。若总是没开始，试着缩小动作、换时段或调整措辞 | 区分真实收获与原先的期待 |
| 第7天 | 看启动是否变容易、行为本身是否值得继续，再决定保留、调整或停止 | 得到一条有记录支持的判断，不以连续打卡定成败 |

可选提示语：

> 晚饭后，我会把喜欢的一段文字读出声。因为我想慢下来，认真体会它；读完一小段，我就觉得踏实。

每天只记一行：`场景是否出现｜是否开始｜启动难度（1—5）｜真实好处或障碍`。漏一次，下次条件出现就继续，无须补时。若没有感受到好处，就如实记录，不需要为了符合脚本而编造反馈。

七天只用来检验是否更容易开始、是否有实际收获。它不能证明习惯已经形成，也不能单独证明提示语或环境调整的因果效果。
